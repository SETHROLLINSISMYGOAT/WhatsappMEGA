Onboarding & Auth Flow
An Android application demonstrating a WhatsApp-inspired onboarding flow featuring a Splash Screen, Welcome Screen, and Phone Number Authentication using Hilt and Firebase.

🛠 Tech Stack
Language: Kotlin

UI Framework: Jetpack Compose / Android Material UI

Dependency Injection: Dagger-Hilt

Backend & Auth: Firebase Authentication (Phone Auth)

Architecture: MVVM (Model-View-ViewModel) + Repository Pattern

Asynchronous Execution: Kotlin Coroutines & Flow

🚀 Features
Smart Splash Screen: Auto-checks user authentication state and routes directly to Main App or Welcome Screen.

Welcome Screen: WhatsApp-styled terms agreement UI before authentication.

Firebase Phone Auth: OTP-based phone number verification flow.

Clean Architecture: Fully decoupled layer structure with Hilt dependency injection.
